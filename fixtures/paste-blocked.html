Paste-blocked generic text target

No network requests, libraries, clipboard reads, or product automation hooks. Use this local file only as a synthetic destination for Sideclip type-out checks.

Keyboard text: ordinary character input is accepted into the textarea below.

Paste/drop: paste and drop are blocked on purpose so clipboard paste cannot silently satisfy a type-out check.

Tab / Enter limitation: Tab and Enter are real keys. In this page (and many browsers/forms) Tab may move focus out of the textarea and Enter may submit or insert a line depending on the control. Sideclip warns before typing entries that contain Tab or Enter/CR/LF. Native window/control focus checks cannot see focus changes inside the page DOM, so completion means keys were sent, not that insertion was verified.
